# ZEL — creative agency visual study

Recreates the supplied Lusion reference through the end of “Where Creative Ideas Become Immersive Experiences”, branded ZEL.

## Run

```sh
npm install
npm run build
npm run dev
```

Preview: http://localhost:5173

`npm run check` validates navigation, dialogs, sound controls, project collection, project brief downloads, asset paths and stylesheet syntax.

## Experience

Custom Three.js sculpture made from hollow rounded cross forms. Pointer movement tilts the composition; clicks scatter it; dragging rotates it. GSAP and Lenis coordinate scrolling, ribbons, title movement, the reel and device presentation. Ambient audio and UI sounds activate through the sound button. Videos load near the viewport. Reduced motion stops continuous motion and video loops. Navigation and media dialogs support keyboard dismissal and focus restoration.

The contact form prepares a local downloadable brief. No messages are submitted to a server; a real contact destination should be configured before a public agency launch.

## Reference media

Design reference: https://lusion.co/ and the user’s a.png–f.png screenshots.
Project imagery, reel preview, ambient audio and UI sounds are Lusion reference media and are credited in the page and media viewers. These projects are clearly identified as visual references, not ZEL client work. Replace the media with ZEL’s licensed assets before using the site as an original public portfolio. The page and 3D implementation are newly authored.

The reference’s Aeonik Regular web font is included for accurate typography in this private visual study, with Arial/Helvetica fallbacks. The reference media and font retain their original ownership; use appropriate licenses or replacements for a public agency launch.
